File Integrity Checker

Built a File Integrity Monitoring tool that detects unauthorised file creation, modification, and deletion by comparing SHA-256 hashes against a stored baseline.

Tracks file size, permissions, UID/GID ownership, timestamps, and inode metadata. The baseline uses cryptographic signature verification to detect tampering with the reference data itself. Structured logs and alerts report integrity violations for investigation.
